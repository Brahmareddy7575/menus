# Food Delivery Application

## Project Overview
The Food Delivery Application is a web-based platform that allows customers to explore food items, view menus, and order food online.

The project is developed using Django for the backend and React.js for the frontend.

## Technologies Used

**Backend:**
- Python
- Django
- Django REST Framework

**Frontend:**
- React.js
- HTML
- CSS
- JavaScript

**Database:**
- MySQL

**Version Control:**
- Git
- GitHub

## Project Features

- Restaurant management
- Food category management
- Food menu display
- Add to cart functionality
- Order management
- REST API integration

## Installation and Setup

1. Clone the repository.
2. Install the required Python packages.
3. Configure the MySQL database.
4. Run Django migrations.
5. Start the Django development server.
6. Start the React frontend.

## Purpose

This project demonstrates full-stack web development using Django, React.js, REST APIs, and MySQL.
